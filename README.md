# Municipal Services Application

## Overview

The Municipal Services Application is a C# Windows Forms application
developed to allow South African residents to report municipal issues.

## Technologies

- C#
- .NET Framework
- Windows Forms
- Visual Studio

## Features

- Report Issues
- Select an issue category
- Enter an issue location
- Enter a detailed description
- Attach images or documents
- Dynamic progress indicator
- Encouraging engagement messages
- Input validation
- Success and error feedback
- Unique issue reference number
- List-based storage of issue reports

## How to Compile

1. Open the solution in Visual Studio.
2. Open the MunicipalServicesApplication solution.
3. Build the solution using Build > Build Solution.
4. Ensure that there are no build errors.

## How to Run

1. Open the solution in Visual Studio.
2. Press F5 or select Start.
3. The Municipal Services Application main menu will appear.

## How to Use

1. Select Report Issues.
2. Enter the location of the issue.
3. Select a category.
4. Enter a detailed description.
5. Attach an image or document if required.
6. Monitor the reporting progress.
7. Click Submit.
8. A confirmation message and reference number will be displayed.

## Data Structure

The application uses a List<IssueReport> to store
user-reported issues.

## Future Features

Local Events and Announcements and Service Request Status
are disabled in Part 1 and will be implemented in later parts
